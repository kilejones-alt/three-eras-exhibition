# The Third Era exhibition

The public exhibition site for **The Third Era: Antizionism and the History of Jew-Hatred**.

Open `index.html` for the homepage. Its three text-only pills lead to `antijudaism.html`, `antisemitism.html`, and `exhibition.html`. The Antizionism page ends with three text-only pills leading to `colonizer.html`, `apartheid.html`, and `genocide.html`. Visitors can continue forward through the exhibition.

Artwork sits in separate lit frames. The three era-opening images have no visible object labels; gallery and timeline images retain compact expandable labels. Hovering lifts a frame and slowly enlarges the image over 5.4 seconds. Transitions and hover motion respect reduced-motion settings.

The homepage opens with `home-film.mp4`, copied byte-for-byte from the supplied `11490316-uhd_3840_1624_24fps.mp4`. The black-and-white appearance is a CSS display treatment; the source video is unchanged. The film starts silently and loops on all screen sizes when the browser permits muted autoplay; it has a play/pause button and stays still for visitors who prefer reduced motion. The Antizionism page also opens with a silent looping film copied byte-for-byte from the supplied `13654703_1920_1080_25fps.mp4`. Both films receive a grayscale CSS display treatment; neither source file is altered. The Antizionism timeline shows original archival images above the moments they illustrate, including the 1941 meeting, Soviet campaign, and Fayez Sayegh. The images are copied unchanged from the earlier exhibition bundle. The timeline uses spacing without a colored rail or section dividers.

Homepage body wording follows the [Exhibition Home Page wording](https://docs.google.com/document/d/1YOFaamw5o2xQMaJ7MElMXHnTY1889-4bBPNnE30OEHY/edit) document. The opening now shows only the title, as requested. Original artwork files remain in the repository. `door-antizionism-naya-clean.jpg` is a manually cleaned copy that removes a camera icon from the original file without AI image generation or editing.

Typography uses Cormorant Garamond for display titles and Source Serif 4 for reading text.

The gallery uses a single black background. Page links use a soft dark transition with a faint central glow. The homepage and era introductions use balanced paragraphs instead of short isolated lines. The Three Streams section is two paragraphs, and the three era titles sit in balanced columns beside their images. Each timeline moment's prose reads as one paragraph, and gallery object-detail controls use a compact size.

The site is static HTML, CSS, JavaScript, and media files. No build step is required.

The header uses a compact four-bar sound symbol, followed by English, Hebrew, and Russian controls in one row. The sound symbol has a spoken label and pressed state for assistive technology.

Film controls use a compact grayscale play/pause symbol just beneath the film at its right edge. The grayscale logo moves diagonally and gains a subtle glow on hover. No new site color is applied.
